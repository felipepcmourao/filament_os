# Estrutura de Pastas

## Contexto
Esse é um projeto para ser construído durante uma sequência de aulas que ficam mais complexas com o passar do tempo.

## Decisão
Tendo em vista, o crescimento programado do projeto e a necessidade de tê-lo organizado desde o princípio, viu-se necessário adotar a organização de pastas em `feature-first`.

Essa forma de organização também é vista como padrão, em grande parte dos trabalhos atuais.

## Consequências
Essa forma de organização garante um maior controle sobre as features do projeto mesmo com o crescimento do projeto.

Cada pasta guardará todos os arquivos ligados a determinada feature para que seja mais fácil a manutenção e futuramente a divisão do trabalho em equipes.
